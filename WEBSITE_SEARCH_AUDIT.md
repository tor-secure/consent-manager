## SERP issue: “Coming Soon” (user screenshot)

| Check | Result |
|-------|--------|
| Repo titles/descriptions contain “Coming Soon” | **No** (only unrelated “Video coming soon” in learning UI) |
| Live homepage `<title>` (fetch 2026-10-17) | Already product title (pre-change): *Consent Management Platform \| Privacy & Cookie Consent Manager* |
| Google snippet in screenshot | **Stale / cached** title *Consent Guru — Coming Soon* and old description *A modern consent management platform…* |

**Conclusion:** The SERP string is **not** generated by current code or current live HTML. Fixing it requires **redeploy of updated metadata** + **Google re-crawl / URL Inspection → Request indexing** (owner action in Search Console). This pass updates titles/descriptions and canonical host so the next crawl can replace the obsolete “Coming Soon” result.

Sitelinks (second screenshot style) are **automated by Google** ([Search Central — Sitelinks](https://developers.google.com/search/docs/appearance/sitelinks)). They cannot be forced with Schema.org `SiteNavigationElement`. This pass strengthens titles, unique descriptions, crawlable nav/footer, and sitemap signals that sitelinks algorithms use.

## Confirmed problems (pre-fix)

1. **Stale Google title “Coming Soon”** — external cache; live HTML already updated previously.  
2. **Host inconsistency** — Google shows `www`; code used `https://consentguru.com`; privacy copy references `www`. Risk of split signals.  
3. **About metadata mismatch** — HTML title vs Open Graph title/description differed; “ConsentGuru” vs “Consent Guru”.  
4. **Missing `public/apple-icon.png`** while layout referenced it.  
5. **`robots.txt` allow-list verbosity** — unnecessary path allowlist (allow `/` is sufficient with disallows). Learning sign-in paths were not disallowed.  
6. **Sitelink readiness** — several hub pages used short/generic titles (`FAQs`, thin OG alignment); Privacy Centre not in primary Company nav.  
7. **OG asset** — `public/og/consent-guru-share.png` **exists** (earlier inventory gap was incorrect for this workspace).
